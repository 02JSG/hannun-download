# 한눈 대시보드

바탕화면 맨 뒤에 붙어 있는 위젯 대시보드예요. 시계·날씨·달력·할 일·메일·음악과 가사·시스템 온도·펫 등
**위젯 45가지**를 원하는 자리에 놓고, **스타일 11가지**로 꾸밀 수 있어요. 다른 창을 가리지 않고, 원하는 모니터에 띄울 수 있어요.

소개·설치 방법: **https://hannun.web.app**

## 받기

**[최신 버전 받기 →](../../releases/latest)**

`HannunDashboard-Setup-<버전>.exe` 를 받아 실행하면 끝이에요. 관리자 권한 없이 설치돼요.
처음 켜면 **한눈 계정으로 로그인**해요. 계정이 없으면 그 자리에서 바로 가입할 수 있어요.

- **파란 경고창**(Windows의 PC 보호)이 뜨면 **추가 정보 → 실행**을 눌러 주세요. 아직 코드 서명을 하지 않아서 뜨는 창이에요.
- 받은 파일이 올라온 것과 같은지 보려면: 같은 Release 의 `.sha256` 파일 안 지문과 비교해요.
  PowerShell 에서 `Get-FileHash HannunDashboard-Setup-<버전>.exe`

## 필요한 것
- Windows 10 / 11 (64비트)
- Microsoft Edge WebView2 — Windows 11 에는 기본으로 있어요
- (선택) CPU·GPU 온도: 앱 안에서 LibreHardwareMonitor 를 자동으로 설치할 수 있어요

## 업데이트
새 버전이 나오면 대시보드 **왼쪽 위**와 **윈도우 알림**으로 **'새로운 버전이 있어요'** 가 떠요.
**지금 업데이트**를 누르면 앱이 알아서 받아 설치하고 다시 켜져요. 내 설정·배치는 그대로 남아요.

> **버전 번호를 새로 정리했어요 (2026-11-21)**: 예전 1.1~1.4 → 1.1, 1.5 → 1.2, 1.5.1 → 1.2.1, 1.5.2 → 1.2.2.
> 예전 번호(1.3 ~ 1.5.x)를 쓰고 있다면 새 버전 알림이 오지 않으니, **이번 한 번만** 위에서 최신 설치 파일을 받아 그대로 덮어 설치해 주세요.

## 개인정보
내 배치·설정·할 일·메모·사진은 **내 컴퓨터에만** 저장돼요. 인터넷으로 나가는 것은 앱 안
설정 → 도움말 → '14. 개인정보'에 모두 적어 두었어요.
